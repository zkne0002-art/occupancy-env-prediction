occenv.cleaning

Cleaning and regularisation of the raw environmental and occupancy extracts.

Both sources are put on the same regular 10-minute UTC grid so they can be joined.

Environmental data (clean_env)

  • The timestamp inside the JSON (Unix seconds, UTC) is the true measurement time; createdate is only when the record was ingested.
  • Exact repeats of (sensorid, measurement time) are removed. In the MSI extract about three quarters of rows are repeats of stale readings.
  • A value carrying an errorCode or lacking a value becomes NaN.
  • Isolated readings (no neighbour within isolation_gap_s) are treated as stale re-sends and dropped; sensors with fewer than min_readings readings left are dropped.
  • Readings are averaged into 10-minute bins; missing bins are kept as NaN.

Occupancy data (clean_occupancy)

  • The log is a step function: headcount is held from one event to the next, sampled at 1-minute resolution (state at the end of each minute), then aggregated to 10 minutes.
  • A non-zero headcount not refreshed for max_stale_min minutes, or any state not refreshed for max_gap_h hours, is treated as missing (possible sensor outage). A zero headcount may persist (an empty room produces no events).

 44def _require_columns(path, required):
 45    """Raise ``ValueError`` if the CSV at ``path`` lacks any of the ``required`` columns."""
 46    header = list(pd.read_csv(path, nrows=0).columns)
 47    missing = [c for c in required if c not in header]
 48    if missing:
 49        raise ValueError(f"{path}: missing required column(s) {missing}; found {header}")

 52def parse_env_json(js):
 53    """Parse the ``jsondata`` string of one environmental reading.
 54
 55    Args:
 56        js: JSON text: a list of ``{"values": [{"time", "value", ["errorCode"]}],
 57            "variable": {"name", "unit", ...}}`` objects.
 58
 59    Returns:
 60        ``None`` if the text cannot be parsed or has no timestamp. Otherwise a dict with
 61        ``time`` (Unix seconds), ``values`` ({short column name: float, NaN if invalid}),
 62        ``invalid`` (columns set to NaN because of an error code or missing value) and
 63        ``time_mismatch`` (True if any variable's time differs from the row time).
 64    """
 65    try:
 66        payload = json.loads(js)
 67        t = int(payload[0]["values"][0]["time"])
 68    except (ValueError, KeyError, IndexError, TypeError):
 69        return None
 70    values, invalid, mismatch = {}, [], False
 71    for var in payload:
 72        try:
 73            col = VAR_NAMES.get(var["variable"]["name"])
 74            v = (var.get("values") or [{}])[0]
 75        except (KeyError, TypeError, AttributeError):
 76            continue
 77        if col is None:
 78            continue
 79        if int(v.get("time", t)) != t:
 80            mismatch = True
 81        if "errorCode" in v or v.get("value") is None:
 82            values[col] = np.nan
 83            invalid.append(col)
 84        else:
 85            values[col] = float(v["value"])
 86    return {"time": t, "values": values, "invalid": invalid, "time_mismatch": mismatch}

 89def parse_timestamps(s):
 90    """Parse timestamps such as ``2024-01-01 21:00:00+11`` into tz-aware UTC values.
 91
 92    Pandas cannot use its fast ISO path for a two-digit offset (``+11``) and falls back to a
 93    slow per-row parser (about 76 % of the cleaning time on the 9-million-row occupancy file).
 94    The fast path here handles the common fixed-width form: it parses the first 19 characters
 95    with an explicit format and applies the whole-hour offset. Anything else (missing values,
 96    other widths, fractional seconds, ``+05:30`` offsets, bad text) uses the slow general parser,
 97    so results are identical in every case.
 98
 99    Args:
100        s: Series of timestamp strings.
101
102    Returns:
103        Series of ``datetime64[..., UTC]`` with the same index; NaT where unparseable.
104    """
105    s = pd.Series(s)
106    if len(s) and s.notna().all():
107        txt = s.astype(str)
108        if (txt.str.len() == 22).all() and txt.str[-3].isin(["+", "-"]).all():
109            try:
110                naive = pd.to_datetime(txt.str[:19], format="%Y-%m-%d %H:%M:%S")
111                tail = txt.str[-3:]
112                offset = tail.map({u: int(u) for u in tail.unique()})
113                return (naive - pd.to_timedelta(offset, unit="h")).dt.tz_localize("UTC")
114            except ValueError:
115                pass
116    return pd.to_datetime(s, utc=True, errors="coerce")

119def clean_env(path, min_readings=MIN_READINGS, isolation_gap_s=ISOLATION_GAP_S, chunksize=100_000,
120              dedupe_first=True):
121    """Clean the environmental CSV and put it on a regular 10-minute UTC grid.
122
123    Args:
124        path: CSV with at least the columns ``sensorid`` and ``jsondata``.
125        min_readings: Sensors with fewer usable readings after cleaning are dropped.
126        isolation_gap_s: Readings with no neighbour within this many seconds are dropped.
127        chunksize: Rows read per chunk (keeps memory low for large files).
128        dedupe_first: If True (default) repeats are detected from a cheap regex on the
129            timestamp BEFORE the JSON is parsed, so discarded rows are never parsed (about
130            76 % of rows in the MSI extract). False parses every row first (the original,
131            slower order); both give identical output.
132
133    Returns:
134        ``(table, stats)``. ``table`` has columns ``sensorid``, ``time_utc`` (tz-aware UTC,
135        regular 10-minute steps per sensor) and one column per variable in
136        `occenv.config.VAR_NAMES`; empty bins are NaN. ``stats`` is a dict of counts
137        describing what was removed, plus ``sensors_kept`` and ``sensors_dropped``.
138
139    Raises:
140        ValueError: If required columns are missing, nothing can be parsed, or no sensor
141            has enough usable readings.
142    """
143    _require_columns(path, ["sensorid", "jsondata"])
144    stats, seen, rows = Counter(), set(), []
145    for ch in pd.read_csv(path, chunksize=chunksize, dtype={"sensorid": str},
146                          usecols=["sensorid", "jsondata"]):
147        for sid, js in zip(ch["sensorid"], ch["jsondata"]):
148            stats["raw rows"] += 1
149            if dedupe_first:
150                m = TIME_RE.search(js) if isinstance(js, str) else None
151                if m is not None and (sid, int(m.group(1))) in seen:
152                    stats["duplicate rows removed"] += 1
153                    continue
154            parsed = parse_env_json(js)
155            if parsed is None:
156                stats["unparseable rows"] += 1
157                continue
158            key = (sid, parsed["time"])
159            if key in seen:
160                stats["duplicate rows removed"] += 1
161                continue
162            seen.add(key)
163            if parsed["time_mismatch"]:
164                stats["variable time != row time"] += 1
165            for col in parsed["invalid"]:
166                stats[f"invalid value -> NaN: {col}"] += 1
167            rows.append({"sensorid": sid, "time": parsed["time"], **parsed["values"]})
168    if not rows:
169        raise ValueError(f"{path}: no parseable environmental readings found")
170
171    df = pd.DataFrame(rows).sort_values(["sensorid", "time"])
172    for col in VAR_NAMES.values():
173        if col not in df.columns:
174            df[col] = np.nan
175    stats["unique readings"] = len(df)
176    sensors_before = set(df["sensorid"])
177    unique_per_sensor = df.groupby("sensorid").size().to_dict()
178
179    g = df.groupby("sensorid")["time"]
180    keep = (g.diff() <= isolation_gap_s) | (-g.diff(-1) <= isolation_gap_s)
181    stats["isolated/stale readings removed"] = int((~keep).sum())
182    df = df[keep]
183    counts = df["sensorid"].value_counts()
184    df = df[df["sensorid"].isin(counts[counts >= min_readings].index)]
185    if df.empty:
186        raise ValueError(f"{path}: no sensor has at least {min_readings} usable readings")
187    out_stats = dict(stats)
188    out_stats["unique_per_sensor"] = unique_per_sensor
189    out_stats["sensors_kept"] = sorted(set(df["sensorid"]))
190    out_stats["sensors_dropped"] = sorted(sensors_before - set(df["sensorid"]))
191    for k, v in out_stats.items():
192        logger.info("  %s: %s", k, v)
193
194    df["time_utc"] = pd.to_datetime(df["time"], unit="s", utc=True).dt.floor(BIN)
195    cols = list(VAR_NAMES.values())
196    binned = df.groupby(["sensorid", "time_utc"])[cols].mean()
197    parts = []
198    for sid, b in binned.groupby(level=0):
199        b = b.droplevel(0)
200        full = b.reindex(pd.date_range(b.index.min(), b.index.max(), freq=BIN, name="time_utc"))
201        full.insert(0, "sensorid", sid)
202        parts.append(full)
203        logger.info("  %s: %d bins, %.1f%% empty, %s -> %s", sid, len(full),
204                    100 * full["co2_ppm"].isna().mean(), full.index.min(), full.index.max())
205    return pd.concat(parts).reset_index(), out_stats

208def clean_occupancy(path, max_stale_min=MAX_STALE_MIN, max_gap_h=MAX_GAP_H,
209                    min_valid_frac=MIN_VALID_FRAC):
210    """Convert the occupancy event log to time-weighted 10-minute headcount per space.
211
212    Args:
213        path: CSV with at least ``floorspaceid``, ``headcount`` and ``collecteddate``
214            (timestamps with a UTC offset, e.g. ``2024-01-01 21:00:00+11``).
215        max_stale_min: Non-zero headcount older than this many minutes becomes missing.
216        max_gap_h: Any state older than this many hours becomes missing.
217        min_valid_frac: A 10-minute bin with a smaller fraction of valid minutes is NaN.
218
219    Returns:
220        DataFrame with columns ``floorspaceid``, ``time_utc``, ``mean_headcount``,
221        ``max_headcount``, ``frac_occupied`` (share of valid minutes with headcount > 0),
222        ``valid_frac`` and ``n_events``. Events sharing a timestamp keep the last one.
223
224    Raises:
225        ValueError: If required columns are missing or no valid event remains.
226    """
227    _require_columns(path, ["floorspaceid", "headcount", "collecteddate"])
228    df = pd.read_csv(path, usecols=["floorspaceid", "headcount", "collecteddate"],
229                     dtype={"floorspaceid": "category", "headcount": "float32"})
230    df["t"] = parse_timestamps(df["collecteddate"])
231    df = df.dropna(subset=["t", "headcount"]).drop(columns="collecteddate")
232    if df.empty:
233        raise ValueError(f"{path}: no valid occupancy events")
234    logger.info("Occupancy events used: %d", len(df))
235    parts = []
236    for sid, g in df.groupby("floorspaceid", observed=True):
237        s = (g.sort_values("t", kind="stable").drop_duplicates("t", keep="last")
238             .set_index("t")["headcount"])
239        minute = s.resample("1min").last()                    # state at the end of each minute
240        held = minute.ffill()
241        last_event = pd.Series(minute.index.where(minute.notna()), index=minute.index).ffill()
242        now = pd.Series(minute.index, index=minute.index)
243        age_min = (now - last_event).dt.total_seconds() / 60
244        valid = ((held == 0) & (age_min <= max_gap_h * 60)) | \
245                ((held > 0) & (age_min <= max_stale_min))
246        hc = held.where(valid)
247        occ = (hc > 0).astype(float).where(hc.notna())
248        out = pd.DataFrame({
249            "mean_headcount": hc.resample(BIN).mean(),
250            "max_headcount": hc.resample(BIN).max(),
251            "frac_occupied": occ.resample(BIN).mean(),
252            "valid_frac": hc.notna().resample(BIN).mean(),
253            "n_events": s.resample(BIN).count(),
254        })
255        bad = out["valid_frac"] < min_valid_frac
256        out.loc[bad, ["mean_headcount", "max_headcount", "frac_occupied"]] = np.nan
257        out.index.name = "time_utc"
258        out.insert(0, "floorspaceid", str(sid))
259        parts.append(out.reset_index())
260        v = out["mean_headcount"]
261        logger.info("  %s: %d bins, %.1f%% missing, occupied %.1f%% of valid time, headcount "
262                    "median=%.1f p95=%.1f max=%.0f", str(sid)[:8], len(out), 100 * v.isna().mean(),
263                    100 * out["frac_occupied"].mean(), v.median(), v.quantile(.95),
264                    out["max_headcount"].max())
265    return pd.concat(parts, ignore_index=True)

218        min_valid_frac: A 10-minute bin with a smaller fraction of valid minutes is NaN.
219
220    Returns:
221        DataFrame with columns ``floorspaceid``, ``time_utc``, ``mean_headcount``,
222        ``max_headcount``, ``frac_occupied`` (share of valid minutes with headcount > 0),
223        ``valid_frac`` and ``n_events``. Events sharing a timestamp keep the last one.
224
225    Raises:
226        ValueError: If required columns are missing or no valid event remains.
227    """
228    _require_columns(path, ["floorspaceid", "headcount", "collecteddate"])
229    df = pd.read_csv(path, usecols=["floorspaceid", "headcount", "collecteddate"],
230                     dtype={"floorspaceid": "category", "headcount": "float32"})
231    df["t"] = parse_timestamps(df["collecteddate"])
232    df = df.dropna(subset=["t", "headcount"]).drop(columns="collecteddate")
233    if df.empty:
234        raise ValueError(f"{path}: no valid occupancy events")
235    logger.info("Occupancy events used: %d", len(df))
236    parts = []
237    for sid, g in df.groupby("floorspaceid", observed=True):
238        s = (g.sort_values("t", kind="stable").drop_duplicates("t", keep="last")
239             .set_index("t")["headcount"])
240        minute = s.resample("1min").last()                    # state at the end of each minute
241        held = minute.ffill()
242        last_event = pd.Series(minute.index.where(minute.notna()), index=minute.index).ffill()
243        now = pd.Series(minute.index, index=minute.index)
244        age_min = (now - last_event).dt.total_seconds() / 60
245        valid = ((held == 0) & (age_min <= max_gap_h * 60)) | \
246                ((held > 0) & (age_min <= max_stale_min))
247        hc = held.where(valid)
248        occ = (hc > 0).astype(float).where(hc.notna())
249        out = pd.DataFrame({
250            "mean_headcount": hc.resample(BIN).mean(),
251            "max_headcount": hc.resample(BIN).max(),
252            "frac_occupied": occ.resample(BIN).mean(),
253            "valid_frac": hc.notna().resample(BIN).mean(),
254            "n_events": s.resample(BIN).count(),
255        })
256        bad = out["valid_frac"] < min_valid_frac
257        out.loc[bad, ["mean_headcount", "max_headcount", "frac_occupied"]] = np.nan
258        out.index.name = "time_utc"
259        out.insert(0, "floorspaceid", str(sid))
260        parts.append(out.reset_index())
261        v = out["mean_headcount"]
262        logger.info("  %s: %d bins, %.1f%% missing, occupied %.1f%% of valid time, headcount "
263                    "median=%.1f p95=%.1f max=%.0f", str(sid)[:8], len(out), 100 * v.isna().mean(),
264                    100 * out["frac_occupied"].mean(), v.median(), v.quantile(.95),
265                    out["max_headcount"].max())
266    return pd.concat(parts, ignore_index=True)

Convert the occupancy event log to time-weighted 10-minute headcount per space.

Arguments:
  • path: CSV with at least floorspaceid, headcount and collecteddate (timestamps with a UTC offset, e.g. 2024-01-01 21:00:00+11).
  • max_stale_min: Non-zero headcount older than this many minutes becomes missing.
  • max_gap_h: Any state older than this many hours becomes missing.
  • min_valid_frac: A 10-minute bin with a smaller fraction of valid minutes is NaN.
Returns:

DataFrame with columns floorspaceid, time_utc, mean_headcount, max_headcount, frac_occupied (share of valid minutes with headcount > 0), valid_frac and n_events. Events sharing a timestamp keep the last one.

Raises:
  • ValueError: If required columns are missing or no valid event remains.
